# 3D-Printed Enclosure

Store enclosure design and fabrication files here, such as:

- source CAD files;
- STL or 3MF exports;
- slicer profiles where useful;
- dimensioned drawings;
- assembly notes and hardware lists;
- enclosure photographs or renders specific to fabrication.

Document the supported display board revision, print orientation, material,
supports, fasteners, and any post-processing required for each released design.
